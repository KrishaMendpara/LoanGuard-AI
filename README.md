# 🛡️ LoanGuard AI
### Intelligent Credit Risk & Loan Default Prediction Platform

All project files, models, dataset, and code are located in `LoanGuardAI/`.

To run the application:
```bash
streamlit run app.py
```
Or:
```bash
cd LoanGuardAI
streamlit run app.py
```

To re-train the models:
```bash
python train_model.py
```

See [LoanGuardAI/README.md](LoanGuardAI/README.md) for full project documentation and architectural specifications.
